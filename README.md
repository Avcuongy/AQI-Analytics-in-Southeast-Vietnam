# Tutorial

## Setup:

```
git clone https://github.com/Avcuongy/AQI-Analytics-in-Southeast-Vietnam.git

cd AQI-Analytics-in-Southeast-Vietnam

python -m venv .venv

.venv\Scripts\Activate.ps1

pip install -r requirements.txt

pip install -e .
```
